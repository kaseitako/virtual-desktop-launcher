## 公開対象の整理

- 元の Git 履歴は引き継がず、点検済みの現行ファイルから新しい履歴を作成しました。
- 個人用の `virtual-desktop-setting.json`、ログ、元リポジトリの開発用設計資料・作業計画は移植対象から除外しました。
- 個人設定、ログ、テスト依存ツールを `.gitignore` で除外しました。公開する JSON はサンプルとスキーマです。
- README のユーザーディレクトリ例を `%APPDATA%` に変更し、取得・設定作成・テスト手順を追加しました。
- JSON Schema の `$id` と Windows スタートアップのパス例を移行先に合わせました。
- テストが個人設定へ依存しないよう、一時ディレクトリで既定設定を生成します。空白・アポストロフィを含むパスも扱います。
- テストの子プロセスと出力の読み取りを UTF-8 にそろえ、日本語以外の Windows 環境でもメッセージを検証できるようにしました。
- Windows 用 GitHub Actions と Pester 4.10.1 のテスト実行スクリプトを追加しました。
- PSVirtualDesktop 由来の関数について、[第三者の著作権・ライセンス表示](../THIRD_PARTY_NOTICES.md)を追加しました。プロジェクト全体のライセンスは新規に指定していません。
- コミットの作成者情報には GitHub の公開ハンドルと noreply アドレスを使用します。
